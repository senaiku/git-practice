# git-practice

Репозиторий создан для изучения Git и GitHub.

## Этапы практической работы
1. Создание локального репозитория, двух файлов и первых коммитов, добавление `.gitignore`.
2. Работа с ветками: создание `feature-branch` и слияние fast-forward.
3. Намеренный конфликт слияния в `file1.txt` и его ручное разрешение.
4. Просмотр истории командой `git log --oneline --graph --decorate --all`.
5. Публикация репозитория и веток на GitHub.
6. Создание `README.md` на GitHub и получение его командой `git pull`.

## Технологии
Git, GitHub
